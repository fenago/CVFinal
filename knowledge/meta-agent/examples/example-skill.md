---
name: contrast-check
description: Check text/background contrast against HIG minimums (4.5:1 small text, 3:1 large/bold). Use when reviewing colours or screenshots.
---
1. List each text colour/background pair from the CSS tokens.
2. Compute the WCAG contrast ratio.
3. Flag pairs below 4.5:1 (≤17px) or 3:1 (≥18px or bold).
