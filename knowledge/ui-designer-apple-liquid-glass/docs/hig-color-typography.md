# HIG: color and typography for the UI

Sources: https://developer.apple.com/design/human-interface-guidelines/color · https://developer.apple.com/design/human-interface-guidelines/typography · https://developer.apple.com/design/human-interface-guidelines/accessibility

- "Use color sparingly, especially on glass." "By default, Liquid Glass has no inherent color, and instead takes on colors from the content directly behind it."
- Use the accent colour for interactive elements and prominent buttons (for example Done).
- System colours: red, orange, yellow, green, mint, teal, cyan, blue, indigo, purple, pink, brown, gray (+ systemGray2–6).
- "Make sure all your app's colors work well in light, dark, and increased contrast contexts."
- "Avoid relying solely on color to differentiate between objects, indicate interactivity, or communicate essential information."
- Type: SF Pro system font. iOS body 17 pt, minimum 11 pt. Few typefaces. Contrast 4.5:1 (small) / 3:1 (large, bold).
- Web mapping (our convention): `font-family: -apple-system, BlinkMacSystemFont, "SF Pro Text", system-ui, sans-serif`. Systemish blue `#007AFF` (light) / `#0A84FF` (dark). Red `#FF3B30` / `#FF453A`.
