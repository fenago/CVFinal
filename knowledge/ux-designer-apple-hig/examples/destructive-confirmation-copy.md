# Example: destructive confirmation copy (HIG-style)

**Reset app data** (uncommon and irreversible, so confirm):
- Title: "Reset app data?"
- Message: "This deletes all saved scans and settings on this device. It can't be undone."
- Buttons: **Cancel** (default) · **Reset** (destructive style)

**Delete one scan** (common action: offer Undo instead of an alert):
- Toast: "Scan deleted." [Undo]
