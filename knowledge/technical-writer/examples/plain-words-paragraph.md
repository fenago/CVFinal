# Example: plain words, with an analogy

> **WebAssembly: the fast engine.** OpenCV was written in C++, a language built for speed. WebAssembly is a compact format that lets the browser run that C++ code almost as fast as a normal desktop program. Think of it as shipping a pre-built engine instead of the blueprints: your browser downloads it once and runs it right on your device. Your photos never leave your computer.
