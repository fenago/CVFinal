# Facts for the plain-words explainers (with sources)

- **OpenCV.js** is OpenCV (a C++ computer-vision library) compiled to run in the browser. Tutorials: https://docs.opencv.org/4.13.0/d5/d10/tutorial_js_root.html
- **WebAssembly**: "a binary instruction format for a stack-based virtual machine… a portable compilation target" (https://webassembly.org/). MDN: "runs with near-native performance" (https://developer.mozilla.org/en-US/docs/WebAssembly/Guides/Concepts).
- **Web Worker**: runs scripts "in background threads… without interfering with the user interface" (https://developer.mozilla.org/en-US/docs/Web/API/Web_Workers_API/Using_web_workers).
- **IndexedDB**: "client-side storage of significant amounts of structured data, including files/blobs" (https://developer.mozilla.org/en-US/docs/Web/API/IndexedDB_API). Data stays on the device, per website (same-origin).
- **Clearing data**: Chrome DevTools → Application → Storage → Clear site data (https://developer.chrome.com/docs/devtools/storage/indexeddb).
- **Netlify deploy**: netlify.toml at the repo root, publish directory (https://docs.netlify.com/build/configure-builds/file-based-configuration/).
